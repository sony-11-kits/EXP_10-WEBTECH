# ASTRA TIDE – Node.js Server Application

**Experiment 10: Developing a Server-Side Application Using Node.js**

## Description
ASTRA TIDE is a simple server-side web application developed using Node.js. It uses the built-in HTTP module to handle client requests and send responses.

## Technologies Used
- Node.js
- JavaScript
- HTML
- CSS
- HTTP Module

## Features
- HTTP server creation
- Request and response handling
- Home page (`/home`)
- About page (`/about`)
- Request URL and request method display
- Black and gold themed interface

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
node server.js
```

5. Open `http://localhost:3000` in your browser.

## Routes
- `/home` – Home page
- `/about` – About page
- `/horoscope` – Horoscope page
